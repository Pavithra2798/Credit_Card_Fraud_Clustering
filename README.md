# Credit Card Fraud Detection

In a world of countless credit card transactions, fraud hides in plain sight—rare and often unlabeled. This project uses unsupervised learning to detect such anomalies without prior knowledge of what fraud looks like.

By applying clustering algorithms like K-Means and DBSCAN, we group similar transaction behaviors and isolate unusual patterns that may indicate fraud. Dimensionality reduction techniques help visualize these hidden structures, making the invisible visible.

This approach shows how clustering can uncover insights in high-volume data, offering a foundation for fraud detection when labeled examples are scarce or unavailable.
